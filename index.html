Multiple administrator access

Invite additional administrators through Supabase Authentication, then grant their user ID the admin role in the SQL Editor. Do not share the project service-role key.

  1. Create the person's account in Supabase Authentication.
  2. Copy their Auth user UUID.
  3. Run the provided grant_admin.sql template with that UUID.

Only authorised admin accounts can change tournament data. All signed-in admins share the same admin permissions in this initial build.
